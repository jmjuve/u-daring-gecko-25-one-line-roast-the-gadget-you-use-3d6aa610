Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610): a program that writes one original line roasting a gadget used every day.

## The roast

> My smartwatch congratulates me every time I stand up, like getting off the couch is a personal best it coached me through.

## Run

```sh
python3 main.py
```

Writes the roast to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and prints the character count. Deterministic — the same output on every run. Python 3.13, standard library only, no network.
